Frontend Email Simulation & Backend Architecture

Pure browser JavaScript does not send real emails or store sensitive SMTP credentials. Every registration, issue submission, field assignment, and resolution triggers an event via emailService.js, storing full HTML payloads in localStorage.jansetu_email_logs. In production, this service connects to AWS SES, SendGrid, or Postmark via authenticated backend REST endpoints. Click "Inspect Email" below to view the rendered email template.
